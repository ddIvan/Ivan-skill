# 需求澄清提问模板

开发任何项目前，先对照下表，**只询问用户未明确给出的选项**。

## 提问清单

| # | 项目 | 默认值 | 询问场景 | 示例提问 |
|---|------|--------|----------|----------|
| 1 | 项目名称 | — | 始终询问 | "项目英文名和中文显示名分别是什么？" |
| 2 | 数据库 | SQLite | 未指定时 | "数据库用 SQLite / MSSQL / MySQL 哪个？" |
| 3 | UI 组件库 | Element Plus | 未指定时 | "UI 组件库用 Element Plus 吗？还是有其他偏好？" |
| 4 | 认证方式 | JWT 登录 | 未指定时 | "系统需要登录和权限管理吗？" |
| 5 | 部署环境 | IIS | 未指定时 | "发布目标环境是 Windows IIS 吗？" |
| 6 | 功能模块 | — | 始终询问 | "本次要开发哪些功能模块？请列出清单。" |
| 7 | 端口 | 前端 5173 / 后端 5000 | 有冲突或特殊要求时 | "后端 API 端口用哪个？" |

## 默认值速查（用户不做选择时）

- 数据库：**SQLite**（`Data Source=app.db`）
- UI 组件库：**Element Plus**
- 认证：**JWT**（登录 + 用户表 + 简单角色）
- 部署：**IIS**（后端 ANCM 托管 + 前端静态发布）
- 端口：前端 `5173`、后端 `5000`

## 注意事项

- 一次只问最关键的 2~3 项，不要一次性抛出全部问题让用户填写。
- 用户给出答案后立即记录到项目方案中，后续开发不再重复询问。
- 若用户说"你看着办"，采用默认值并明确告知，随后直接开发。
